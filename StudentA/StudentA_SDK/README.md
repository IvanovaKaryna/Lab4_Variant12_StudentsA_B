StudentA Dynamic Library

1. Опис бібліотеки
Бібліотека призначена для виконання комбінаторних обчислень мовою C++.
Вона містить функції для обчислення факторіала, перестановок, комбінацій і розміщень.

2. Функції бібліотеки
long long factorial(int n) - обчислює факторіал числа n
long long permutations(int n) - обчислює кількість перестановок n елементів
long long combinations(int n, int k) - обчислює кількість комбінацій із n елементів по k
long long arrangements(int n, int k) - обчислює кількість розміщень із n елементів по k

3. Вхідні дані
n - невід’ємне ціле число
k - невід’ємне ціле число, яке не перевищує n

4. Результати та обмеження
Функції повертають результат типу long long
Для коректної роботи необхідно передавати допустимі аргументи. Для комбінацій і розміщень значення k не повинно перевищувати n
Для великих значень аргументів можливе переповнення типу результату. Поведінка функцій при передаванні недопустимих аргументів залежить від їх реалізації

5. Приклади перевірки
factorial(5) = 120
permutations(4) = 24
combinations(5, 2) = 10
arrangements(5, 2) = 20

6. Склад SDK
include/StudentA_Dynamic.h - заголовковий файл
lib/StudentA_Dynamic.lib - бібліотека для неявного зв’язування
bin/StudentA_Dynamic.dll - динамічна бібліотека

7. Використання
Бібліотека підтримує неявне та явне зв’язування. Для неявного зв’язування використовуються заголовковий файл і файл .lib
Для явного зв’язування DLL завантажується за допомогою LoadLibrary(), а адреси функцій отримуються за допомогою GetProcAddress()
