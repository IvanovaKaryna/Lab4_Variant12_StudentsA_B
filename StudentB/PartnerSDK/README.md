# StudentA Dynamic Library

## Опис бібліотеки

Бібліотека призначена для виконання комбінаторних обчислень мовою C++.

## Функції

factorial(n) - обчислення факторіала числа.
permutations(n) - обчислення кількості перестановок.
combinations(n, k) - обчислення кількості комбінацій.
arrangements(n, k) - обчислення кількості розміщень.

## Склад SDK

include/StudentA_Dynamic.h - заголовковий файл.
lib/StudentA_Dynamic.lib - бібліотека для неявного зв’язування.
bin/StudentA_Dynamic.dll - динамічна бібліотека.

## Приклади перевірки

factorial(5) = 120
permutations(4) = 24
combinations(5, 2) = 10
arrangements(5, 2) = 20

## Контракт

Перед використанням функцій потрібно передавати допустимі аргументи. Для факторіала та перестановок число n має бути невід’ємним.
Для комбінацій і розміщень числа n та k мають бути невід’ємними, причому k не повинно перевищувати n. Для великих значень можливе переповнення типу результату.
